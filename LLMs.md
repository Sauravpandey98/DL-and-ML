## Important Finding about LLMs in form of questions and answers

1. What are different stages of LLM training?

Ans: There are three stages of LLM training:
   - Pre-Training: Here we use self supervised training method to train the model on avery huge amount of text obtained from internet,books etc.In this stage,the model learn to predict the next token in a sequence of tokens.For a single sequenece of token,multiple training examples are created by masking the tokens and the model is trained to predict the masked tokens.Here the model learns the general language understanding.Example foundation models are GPT-3,BERT etc.
   - Fine-Tuning: In this stage,the model is fine-tuned on a dataset that consists of intruction and responses.It is a form supervised learning where the model is trained to predict the response given the instruction.Here the model learns to follow specific instructions and generate responses accordingly.
   Through SFT we can fine-tune the model to perform specific tasks like translation, summarization,legal document analysis etc.The example of this stage is InstructGPT(trained from GPT-3) and T5.
   - RLHF(Reinforcement Learning from Human Feedback): In this stage,the model is trained using reinformcement learning.Here we use a reward model that is trained to predict the quality of the response given the instruction and the response generated by the model.The model is trained to generate responses that are rated highly by the reward model.This type of training can be used to fine-tune the model where quality of response is more important than following the instruction exactly or where there can be many responses to a single intruction,but we have to choose the best one(Chess Game).The example of model trained using RLHF is ChatGPT.

2. What is PEFT?

Ans:  PEFT(Parameter Efficient Fine-Tuning): It is a method to fine-tune the model using a small amount of data and computation.It is used to fine-tune the model on a specific task using a small amount of data and computation.The best way to train a model using PEFT is LoRA.

3. What is LoRA?

Ans: Low Rank Adaptation(LoRA): It is a method to fine-tune the model using a small amount of data and computation.In LoRA,we use a low rank matrix to represent the weights of the model and fine-tune the model using this low rank matrix.The low rank matrix is learned using the data and the model is fine-tuned using this low rank matrix.This method is used to fine-tune the model using a small amount of data and computation.

During training of model,the weights updates can be represent as:
    W = W + ΔW
    where W is the weight matrix of the model and ΔW is the update to the weight matrix.

Now the ΔW is will have the size of W which is very large and it is computationally expensive to update the weights using this large matrix.

So we utilise that the weight matrix W can be represented as a product of two matrices U and V where U is of size (m x r) and V is of size (r x n) where r is the rank of the matrix.

Higher the rank of the matrix,more the number of parameters in the model and more the computation required to update the weights.As we increase r,the complextiy of model increases.

During training we freeze the base model weights and only update the low rank matrix U and V.After training these U and V is combined to get the final weight matrix W.

    Final model weights= W(old) + U*V

The most important parameters in LoRA training is r(rank) and alpha.The role of alpha in LoRA is demonstrated in the following equation:

    ΔW = αU*V

A rule of thumb is to set alpha to be 2*r.

4. What is Quantization

Ans Quantization refers to the method of projecting the wieghts of model to lower precision.For example project the float32 weitghs to float16 weights or INT8 weights.This is done by scaling the higher precision weights(float16) having range [−65504,65504] to lower precision weights(INT8) having range [−128,128].This is done to reduce the memory and computation required to store and update the weights of the model.More can be read from [here](https://huggingface.co/docs/optimum/en/concept_guides/quantization) .

5. What is QLoRA?

Ans: So a QLoRA and a LoRA are the same thing. The only difference between them is that a QLoRA quantizes the model that is being trained in order to reduce the memory footprint.

Both require the FP16 or higher weights in order to train, so what QLoRA does is quantize the model to 4-bit at loading time, runs however many steps are needed to reach the first update interval, then upcasts the relevant values back to FP16, performs the update, then quantizes the updated values back to 4-bit.
